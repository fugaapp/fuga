01After downloading

Opening Fuga the first time

Your computer may warn you once, because Fuga is a free app without a paid security certificate. That's normal — the installers are built automatically by GitHub from the public code. After the first launch it opens like any other app.

Windows

  1. Open the downloaded .exe.
  2. If a blue window says "Windows protected your PC", click More info, then Run anyway.
  3. Follow the installer. Fuga appears in the Start menu.

macOS

  1. Open the .dmg and drag Fuga into Applications.
  2. Open Fuga. If macOS says it can't be opened, click Done.
  3. Go to System Settings → Privacy & Security, scroll down and click Open Anyway.

Linux

  1. Right-click the .AppImage → Properties → allow executing as a program (or run chmod +x Fuga-*.AppImage).
  2. Double-click it to start.
  3. If it doesn't open, start it from a terminal with --no-sandbox.

02Updates

Always up to date

For the curious: check that a download is genuine

Every official installer carries a signed record of the exact source code and build that produced it. With the GitHub command-line tool installed, run gh attestation verify <file> --repo fugaapp/fuga.

For developers: build from source

Install Node.js 22, then: git clone https://github.com/fugaapp/fuga.git, cd fuga, npm install, npm run dev.
